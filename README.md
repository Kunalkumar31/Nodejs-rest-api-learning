## ⚙️ Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/nodejs-rest-api-learning.git
cd nodejs-rest-api-learning
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Setup environment variables

Create a `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

### 4️⃣ Run the server

```bash
npm run dev
```

👉 Server will start at:
http://localhost:5000
